# 中小企業診断士2次試験ドリル

スキマ時間用の一問一答ドリル。GitHub Pagesで公開し、スマホのホーム画面に追加してアプリのように使うことを想定しています。

## 公開ページ

- [ポータル](index.html)
- [事例Ⅳ 隙間時間ドリル](case4-drill.html) — 経営分析/CVP/意思決定会計/WACC・企業価値/セグメント/CF計算/解き方・電卓、全79問
- [課題→対応策キーワード変換](keyword-drill.html) — 事例Ⅰ〜Ⅳ横断、全46問

## 仕組み

単一HTMLファイル(外部依存はGoogle Fontsのみ)。正誤記録・苦手リストは `localStorage` にブラウザ内保存されます。同じURLで更新し続ける限り、記録は引き継がれます。

## 更新方法

問題を追加・修正したら、対象ファイルをコミットしてpushするだけで反映されます(GitHub Pagesが自動ビルド)。
